# 상가 계약 전 체크 3단계 — 쇼츠 #1

- 파일: `shorts_final.mp4` (1080×1920, 30fps, 43초, H.264 + AAC, -14 LUFS)
- 목적: 모든AI부동산 1순위 목표, **주소·호수·업종이 들어간 문의** 확보
- 구조: 참고 쇼츠(설득형 광고)의 4단계를 가져옴 — 잘못된 믿음 → 진짜 원인 → 순서 → 부담 없는 첫 행동
- 스타일: 블랙 앤 골드 (블랙 배경 · 골드 포인트 · 경고 표시만 오렌지)
- 내레이션: vidIQ AI 음성(Matilda). 대표님 목소리로 바꾸려면 `src/vo.mp3`를 교체하고 다시 렌더링

## 다시 만들기 (대본·숫자 수정 시)

```bash
cd src
npm install pretendard        # 폰트
python3 audio.py              # 배경음·효과음 → bed.wav
# vo.mp3 + bed.wav 믹스 → mix.wav (ffmpeg sidechaincompress + loudnorm -14 LUFS)
node render.js video_noaudio.mp4
ffmpeg -i video_noaudio.mp4 -i mix.wav -c:v copy -c:a aac -b:a 192k -movflags +faststart -shortest shorts_final.mp4
```
장면 타이밍은 `index.html`의 `SC`(장면)와 `CAPS`(자막) 배열에서 조정.
