# 숨은 정부지원금? AI로 10초 만에 척척! — 쇼츠

- 파일: `gov_shorts.mp4` (1080×1920, 30fps, 19초, 자막 + 배경음악, 내레이션 없음)
- 썸네일: `thumbnail_fixed.png` (휴대폰 말풍선 문구만 교체한 버전)
- 상단 헤드라인은 처음부터 끝까지 고정, 배경(캐릭터)만 천천히 확대

## 원본 대비 바꾼 것
- 휴대폰 말풍선 "3,000만원 맞춤 지원금 선정" → "맞춤 지원사업 3건 찾았어요"
  - 이유: AI가 지원금 선정까지 해 주는 것처럼 보이는 결과 표현은 과장 광고 소지

## 자막
| 시간 | 자막 |
|---|---|
| 0~0.8초 | (썸네일 그대로) |
| 0.8~3.6초 | 사장님이 받을 수 있는 지원금, 놓치고 계시진 않나요? |
| 3.6~7.4초 | 지역 · 업종 · 창업연도 / AI에게 이것만 알려주세요 |
| 7.4~11초 | 기업마당 같은 공식 공고에서 / 조건 맞는 후보를 찾아줍니다 |
| 11~14.6초 | 단, 신청 자격과 마감일은 / 꼭 공고 원문으로 확인! (달력 아이콘 강조) |
| 14.6~19초 | 찾는 질문(프롬프트)이 필요하면 / 문자로 '지원금' 보내주세요 / 010-3973-4338 |

## '지원금' 문자에 보내줄 프롬프트 (웹 검색 되는 AI에서 사용)
```
나는 [광주 서구]에서 [카페]를 운영하는 소상공인이고, [2024년 ○월]에 창업했어.
직원은 [0명], 연매출은 [약 ○천만 원]이야.
지금 신청할 수 있는 정부·지자체 지원사업을 기업마당(bizinfo.go.kr) 등 공식 공고에서 찾아서
사업명 / 지원 내용 / 신청 자격 / 마감일 / 공고 링크를 표로 정리해 줘.
공고 원문에서 확인하지 못한 내용은 '확인 필요'라고 표시해 줘.
```

## 다시 만들기
```bash
cd src && npm install pretendard
python3 audio.py && ffmpeg -i bed.wav -af loudnorm=I=-15:TP=-1.5 -ar 44100 mix.wav
node render.js v_noaudio.mp4
ffmpeg -i v_noaudio.mp4 -i mix.wav -c:v copy -c:a aac -b:a 192k -movflags +faststart -shortest gov_shorts.mp4
```
자막 문구·타이밍은 `index.html`의 `CAPS` 배열에서 수정.
